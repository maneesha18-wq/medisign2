✨ Features

Cutting-edge technology for medical sign language recognition

🎯 Core Features

Real-Time Video Recognition

Upload medical sign language videos and get instant recognition results with high accuracy.

10 Medical Terms

Recognition of essential medical vocabulary: Heart Attack, Diabetes, Broken Arm, Fever, Medication, Headache, Hospital, Surgeon, Emergency, Pain.

Confidence Scores

See the probability scores for all 10 medical terms to understand the model's certainty.

Audio Output

Text-to-speech conversion provides audio feedback for each recognized term.

🧠 AI & Machine Learning

BiLSTM + Attention Architecture

State-of-the-art bidirectional LSTM with attention mechanism for sequence modeling of sign language patterns.

MobileNetV2 Feature Extraction

Pre-trained CNN backbone for efficient 1280-dimensional feature vectors from video frames.

Temporal Understanding

Captures temporal patterns across 60 frames, understanding sign language as a sequence of movements.

High Accuracy

98% accuracy on test dataset with continuous improvement through feedback and retraining.

🚀 Platform Features

Web-Based Interface

No installation required. Access from any modern web browser on desktop or mobile.

Privacy & Security

All video processing happens locally on your server. No data is sent to external services.

Scalable Architecture

Built with Flask and optimized for production deployment with GPU support.

REST API

Full API endpoints for integration with other healthcare applications.

📚 Dataset

124 Training Videos

Diverse dataset of medical sign language videos across all 10 medical terms.

WLASL Integration

Enhanced with World Sign Language dataset for better generalization and robustness.

High Quality

Cleaned and validated dataset with only medical-relevant content. No corrupted files.
